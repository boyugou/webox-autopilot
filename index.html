webox-autopilot is a Claude Code skill suite that turns plain-language meal requests into API-backed WeBox orders. It plans around budget, variety, dietary rules, favorites, hidden items, and your own dish notes.

A skill suite for real ordering, not browsing.

The skills use the same session as your logged-in Chrome browser, then work directly with WeBox endpoints for menus, favorites, hidden items, order history, and order placement.

API-first

Fetch a complete menu in one structured call and place each meal slot with one sequential order POST.

Preference memory

Budget, dietary rules, cuisine bias, avoid lists, favorites, and dish reviews are read every order session.

Transparent state

Local data lives in editable JSON, YAML, and Markdown under Documents instead of a hidden black box.

Careful automation

Sequential writes, optional confirmation, order-history refreshes, and budget validation reduce avoidable mistakes.

From a sentence to a placed order.

Designed for people who already use WeBox and want the repetitive decision work handled with clear rules.

01

Onboard once

Fetch profile, address, favorites, hidden items, order history, and shipping windows through the API.

02

Say the plan

Ask for tomorrow's lunch, a full weekday schedule, favorites only, milks, or an ad-hoc menu search.

03

Apply your rules

Honor budgets, meal defaults, weekend skipping, cuisine preferences, allergens, avoid lists, and recent history.

04

Place and learn

Post orders through the API, save week files, and record feedback like “too salty” or “never again.”

Your rules stay inspectable.

webox-autopilot is intentionally transparent. The skill writes caches and preferences as ordinary local files, so you can inspect, edit, back up, or reset them without a dashboard.

Install once. Run from Claude Code.

Requirements: Claude Code, Chrome with Claude in Chrome, an active WeBox account, and a logged-in browser session. The skill never asks for WeBox credentials. 

git clone https://github.com/boyugou/webox-autopilot.git /tmp/webox-autopilot && bash /tmp/webox-autopilot/install.sh && rm -rf /tmp/webox-autopilot
